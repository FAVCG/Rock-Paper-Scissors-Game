# Rock Paper Scissors Game

## Description
A simple Java console game where the user plays Rock, Paper, Scissors against the computer. The computer randomly selects a choice, and the program determines the winner.

## Features
- Allows the user to choose Rock, Paper, or Scissors
- Generates a random choice for the computer
- Determines the winner or a tie
- Validates user input

## Technologies
- Java
- Scanner class for user input
- Random class to generate the computer's choice
- If-else statements for game logic

## How to Run
1. Open the project in your Java IDE.
2. Run the `RockPaperScissor.java` file.
3. Enter your choice:
   - `0` for Rock
   - `1` for Paper
   - `2` for Scissors
4. See the computer's choice and the game result.
